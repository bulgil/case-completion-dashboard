# План по завершению

Локальный дашборд на Go для контроля плана завершений по Excel-выгрузкам.

## Запуск

```powershell
go run .
```

Откройте `http://localhost:8080`, выберите месяц и загрузите `.xlsx`.

Первая загрузка формирует состав плана и фиксирует исходные статус и дату СЗ. Повторные загрузки сопоставляются по `Контакт: ID` (при его отсутствии — по номеру дела и ФИО), обновляют текущие значения и отмечают переносы СЗ.

Данные хранятся локально в `data/dashboard.json`. Путь можно изменить переменной `DATA_FILE`, адрес сервера — `ADDR`.

# Case Completion Dashboard

Локальное приложение Bitrix24 на Go для сравнения исходного Excel-отчёта с актуальными данными CRM.

## Логика

1. Пользователь открывает приложение внутри Bitrix24 и загружает `.xlsx`.
2. Сервер читает только видимые строки первого листа. Строки, скрытые применённым и сохранённым фильтром Excel, не участвуют.
3. Значения из Excel считаются состоянием на начало периода.
4. Браузер через авторизацию текущего пользователя Bitrix24 пакетно получает контакты и сделки.
5. Статус контакта `UF_CRM_1708427400582` формирует счётчик «Завершено успешно» при точном значении «Завершен успешно».
6. Поле контакта `UF_CRM_1708427240655` сравнивается с исходной датой СЗ и формирует счётчик переносов.
7. В таблице сравниваются исходная и текущая стадии сделки.

Приложение ничего не записывает в БД, не отслеживает сделки в фоне и не сохраняет отчёт после перезагрузки страницы. Кнопка экспорта выгружает текущее состояние таблицы в `.xlsx`.

## Запуск

```bash
task up
task logs
```

Приложение слушает `127.0.0.1:1987`, внутренний путь — `/completion-plan`, внешний путь через Caddy — `/dashboards/completion-plan`.

URL обработчика локального приложения Bitrix24:

```text
https://pravv-dev.ru/dashboards/completion-plan
```

Приложению требуется право REST `CRM`.
